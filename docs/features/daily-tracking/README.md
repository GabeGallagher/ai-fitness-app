# Daily tracking

> Phase 1 (manual entry). Overview: [SPEC.md §6](../../SPEC.md#6-notes-for-later-phases-from-the-interview-not-specified-yet).
> Status: **Not started**

Exercise, steps, water, and notes for a day. It's a feature of its own, not part of Nutrition, because device sync will apply across several parts of the app.

- **In scope:** manual entry.
- **Out of scope for now:** syncing from devices.
- The [Daily log](../nutrition/daily-log/spec.md) shows these values, and the exercise calories logged for a day add to that day's calorie budget ([SPEC.md §5.5](../../SPEC.md#55-targets)).

Add subfeature folders when this is specified. Start from [_template.md](../_template.md).
